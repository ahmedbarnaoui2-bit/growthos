4. TikTok data processing (Operator’s account)

When the Operator authorizes the App, TikTok transmits tokens/identifiers of the Operator’s account to the Operator’s own machine. Tokens are stored in Windows Credential Manager only; nothing is uploaded elsewhere. The Operator can revoke the App’s access at any time from TikTok’s settings (Privacy and Settings → Security → Apps). Revoking deletes the App’s access immediately.
